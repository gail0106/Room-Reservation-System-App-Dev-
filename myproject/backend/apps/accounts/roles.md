# SYSTEM ROLES

We have 3 user roles:

1. Admin
2. Teacher
3. Student

# PERMISSIONS

## ADMIN
- Can create rooms
- Can edit rooms
- Can delete rooms
- Can view all reservations
- Can manage users
- approve reservation requests

## TEACHER
- Can view rooms
- Can create reservations
- Can cancel own reservations

## STUDENT
- Can view rooms
- Can create reservations (limited rules)
- Can cancel own reservations only
